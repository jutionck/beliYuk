# BeliYuk Web Apps

Beliyuk: Oleh Oleh adalah platform e-commerce yang bertujuan untuk menghubungkan konsumen dengan UMKM lokal sekaligus menyediakan berbagai produk oleh-oleh dari destinasi wisata di seluruh Indonesia. Meskipun memiliki konsep yang inovatif, platform ini menghadapi tantangan seperti rendahnya keterlibatan pengguna dan tingkat konversi yang masih di bawah rata-rata industri. Hal ini disebabkan oleh kurangnya rekomendasi yang dipersonalisasi, pengalaman pengguna yang kurang optimal, dan tidak adanya program loyalitas yang efektif. Proyek ini berfokus pada mengatasi masalah tersebut dengan pendekatan berbasis data untuk personalisasi, meningkatkan antarmuka dan pengalaman pengguna, serta merancang program loyalitas yang kuat. Laporan ini menjelaskan tujuan, desain, implementasi, dan hasil dari inisiatif ini, serta memberikan rekomendasi untuk pengembangan ke depan.

## Konfigurasi Awal

- Copy file `.env.example` kemudian buat file baru dengan nama `.env`.
- Sesuaikan isi file `.env` dengan konfigurasi database masing-masing
- Untuk DDL silahkan cek pada folder `assets/database`

## Instalasi Server Lokal

Untuk menjalankan aplikasi di butuhkan sebuah server, disini untuk mempermudah silahkan download dan install XAMPP, link dapat di akses disini https://www.apachefriends.org/

## Jalankan Aplikasi

Jika sudah dilakukan instalasi ulang dan sudah menaruh project ini di `xampp/htdocs` maka sudah otomatis dapat dibuka di browser. Pada URL ketik saja `localhost/<nama-project>`
